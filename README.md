# Бренды, контент и продажи для четырёх бизнесов

Коммерческое предложение в формате сайта-слайдшоу: Unicar, PhuketDrive, Dandy Pizza Sushi, logistics.kaz.

## Как смотреть

Онлайн: https://m1tenka.github.io/Presentation/

GitHub Pages собирает сайт из ветки `gh-pages`. После правок в `main` обновите её: `git push origin main:gh-pages`.

- Колесо мыши, стрелки, PageUp/PageDown, пробел или свайп меняют слайд.
- Кнопки внизу справа листают вперёд и назад, `Home` и `End` ведут к первому и последнему слайду.
- Номер слайда хранится в адресе: `…/#10` откроет сразу десятый.
- На телефоне в портретной ориентации слайды идут обычной лентой с прокруткой.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | 22 слайда |
| `styles.css` | дизайн-токены, сетка, анимации; `1rem` = 10px макета 1440×900 |
| `app.js` | навигация, разбивка заголовков на строки, счётчики |
| `img/` | изображения из макета Figma |
| `fonts/` | шрифт Onest (SIL OFL) |

Макет: Figma, файл Commercial, фрейм «★ Презентация · финал».
